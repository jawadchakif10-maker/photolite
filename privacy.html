Privacy Policy

How PhotoLite handles information when you use this website.

1. Image processing

PhotoLite uses browser features to process the image you select. Image compression, resizing and format conversion are performed locally in your browser. The selected image is not uploaded to a PhotoLite image-processing server.

2. Information and hosting

PhotoLite does not currently ask you to create an account or submit personal information to use the image tool. The website is hosted using GitHub Pages. The hosting provider may process technical information such as IP address, browser details and request logs as part of delivering and securing the website. Please consult GitHub's own privacy information for details about its hosting services.

3. Cookies and analytics

PhotoLite does not currently include its own analytics or advertising cookies. If third-party analytics or advertising services are added later, this policy should be updated before those services are enabled.

4. Children's privacy

PhotoLite is a general-purpose image utility and is not designed to collect personal information from children.

5. Changes

This policy may be updated when the website's features or service providers change. Please review this page periodically.

6. Contact

No dedicated support email is currently published. A contact method will be added if direct support becomes available.
